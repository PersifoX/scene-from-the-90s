# Когда родители были маленькими

Интерактивная 3D-комната о повседневной жизни 1980–1990-х. React, Three.js и React Three Fiber.

```sh
npm ci
npm run dev
```

Сборка: `npm run build`. Просмотр сборки: `npm run preview`.

Для публикации импортируйте репозиторий в Vercel. Настройки сборки заданы в `vercel.json`.

Источники и лицензии материалов: [ASSET-CREDITS.txt](public/ASSET-CREDITS.txt).
